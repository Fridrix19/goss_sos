# Генератор билетов для госэкзамена

Небольшое статическое приложение для генерации теоретических билетов.

## Что умеет

- Разделяет два направления: **Контент** и **ПИД**.
- По кнопке генерирует билет из двух вопросов.
- Вопросы в одном билете берутся из разных тематических блоков, например: «Фотография» + «Информационные системы и технологии».
- Работает без сервера: достаточно открыть `index.html` в браузере.

## Файлы

- `index.html` — разметка приложения.
- `styles.css` — стили интерфейса.
- `app.js` — база вопросов и логика генерации.
